# Browser — Chrome & Edge (Windows)

Most of your apps (SDP and friends) live in a browser, so this is where keyboard skill pays off most.
Almost all of these are identical in Chrome, Edge and Firefox, and on Linux.

---

## Tabs

| Keys | Action |
|---|---|
| `Ctrl + T` | New tab |
| `Ctrl + W` | Close tab |
| `Ctrl + Shift + T` | **Reopen** last closed tab (repeat to go further back) |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | Next / previous tab |
| `Ctrl + PgDn` / `Ctrl + PgUp` | Next / previous tab (alternative) |
| `Ctrl + 1…8` | Jump to tab 1–8 |
| `Ctrl + 9` | Jump to **last** tab |
| `Ctrl + Shift + A` | Search open tabs (Chrome) |
| `Ctrl + N` | New window |
| `Ctrl + Shift + N` | Incognito / InPrivate window (test logins without your cookies) |
| Right-click tab → **Pin** | Keep SDP/Teams web pinned at the left; `Ctrl + 1` always gets it |

## Links

| Action | Result |
|---|---|
| `Ctrl + click` / middle-click | Open in background tab |
| `Ctrl + Shift + click` | Open in new tab and switch to it |
| `Shift + click` | Open in new window |
| `Tab` / `Shift + Tab` | Move focus link to link; `Enter` opens it |

## Navigation

| Keys | Action |
|---|---|
| `Alt + ←` / `Alt + →` | Back / forward |
| `F5` or `Ctrl + R` | Reload |
| `Ctrl + F5` or `Ctrl + Shift + R` | Hard reload (bypass cache — fixes "it looks broken") |
| `Esc` | Stop loading |
| `Space` / `Shift + Space` | Page down / up |
| `Home` / `End` | Top / bottom of page |
| `F11` | Full screen |
| `Ctrl + +` / `Ctrl + -` / `Ctrl + 0` | Zoom in / out / reset |

## Address bar

| Keys | Action |
|---|---|
| `Ctrl + L`, `Alt + D` or `F6` | Focus address bar (and select the URL — `Ctrl + C` copies it) |
| `Ctrl + K` or `Ctrl + E` | Search with default engine |
| `Alt + Enter` | Open what you typed in a **new tab** |
| `Ctrl + Enter` | Add `www.` and `.com` |
| `Shift + Delete` on a suggestion | Remove that autocomplete suggestion |
| `keyword` + `Space` | Use a **site search** shortcut (see below) |

### Site search shortcuts — the biggest time saver

Settings → Search engine → Site search → **Add**. Put `%s` where the search term or ID goes.

| Shortcut | Example URL | Use |
|---|---|---|
| `sdp` | your SDP ticket URL with the number replaced by `%s` | `sdp 48211` → opens the ticket |
| `kb` | your KB search URL with `%s` | `kb vpn` |
| `ad` | your user-lookup page with `%s` | `ad jsmith` |

## Find & select on the page

| Keys | Action |
|---|---|
| `Ctrl + F` | Find |
| `Enter` / `Shift + Enter` | Next / previous match (while find bar is open) |
| `Ctrl + G` / `Ctrl + Shift + G` | Next / previous match |
| `Esc` | Close find — the match stays **selected**, so `Ctrl + C` copies it |
| `F7` | **Caret browsing**: select page text with `Shift + arrows` like a document |

## Forms (web apps like SDP)

| Keys | Action |
|---|---|
| `Tab` / `Shift + Tab` | Next / previous field |
| `Space` | Toggle checkbox / press button |
| `↑` `↓` | Change radio button |
| `Alt + ↓` | Open a standard dropdown |
| Type letters | Jump/filter in a dropdown |
| `Enter` | Submit (careful — in many forms `Enter` in a one-line field submits) |
| `↓` in a field | Show autofill suggestions; `Shift + Delete` removes one |

## Useful for troubleshooting users' browsers

| Keys | Action |
|---|---|
| `Ctrl + Shift + Delete` | Clear browsing data (cache/cookies — the classic fix) |
| `Ctrl + H` | History |
| `Ctrl + J` | Downloads |
| `Ctrl + D` | Bookmark page |
| `Ctrl + Shift + B` | Show / hide bookmarks bar |
| `Ctrl + Shift + O` | Bookmark manager |
| `Ctrl + P` | Print / save as PDF |
| `F12` or `Ctrl + Shift + I` | Developer tools (console errors) |
| `Shift + Esc` | Browser's own task manager (which tab is eating memory) |
| `chrome://settings` / `edge://settings` | Settings pages — type straight in the address bar |

Bookmark-bar trick: rename bookmarks to just an icon (blank name) to fit dozens on the bar,
or put them in folders and use `Ctrl + L`, type part of the name, and pick from suggestions.

# Microsoft Teams (new Teams, Windows desktop app)

**`Ctrl + .`** shows the official list inside Teams — Microsoft changes these, so trust that over any sheet.
In the browser version, some keys differ (e.g. `Ctrl + Alt + E` for search) because the browser owns them.

---

## Getting around

| Keys | Action |
|---|---|
| `Ctrl + .` | Show keyboard shortcuts |
| `Ctrl + E` | Search box (type a person's name to jump to their chat) |
| `Ctrl + N` | New chat |
| `Ctrl + 1, 2, 3…` | Apps in the left bar, in order (Activity, Chat, Teams, Calendar…) |
| `Ctrl + F` | Search inside the current chat / channel |
| `F6` / `Ctrl + F6` | Move focus between regions (left bar, list, conversation, compose) |
| `↑` `↓` | Move through chat list or messages once focused |
| `Ctrl + ,` | Settings |
| `Esc` | Back out of whatever you're in |

## Writing messages

| Keys | Action |
|---|---|
| `Enter` | Send |
| `Shift + Enter` | New line (don't send) |
| `Ctrl + Shift + X` | Expand compose box — then `Enter` = new line, `Ctrl + Enter` = send |
| `Ctrl + B` / `I` / `U` | Bold / italic / underline |
| `Ctrl + Shift + V` | Paste as plain text |
| `@` + name, then `Tab`/`Enter` | Mention someone |
| Type ```` ``` ```` | Start a code block — great for pasting error messages and logs |
| Type `` ` `` around text | Inline code (e.g. a hostname) |
| `↑` (in empty compose box) | Edit your last message (in many versions) |

## Calls & meetings

| Keys | Action |
|---|---|
| `Ctrl + Shift + M` | Mute / unmute |
| `Ctrl + Space` (hold) | Push-to-talk while muted |
| `Ctrl + Shift + O` | Camera on / off |
| `Ctrl + Shift + E` | Share screen |
| `Ctrl + Shift + K` | Raise / lower hand |
| `Ctrl + Shift + A` | Accept audio call |
| `Ctrl + Shift + S` | Accept video call |
| `Ctrl + Shift + D` | Decline call |
| `Ctrl + Shift + H` | Leave / hang up |

## Habits that save time

- Pin your team lead and the main help-desk channel (`…` → Pin) so they're always at the top.
- Use **Saved messages** (bookmark a message) for instructions you'll need again.
- `Win + Shift + S` then `Ctrl + V` in a chat = instant screenshot to a colleague.
- Set Teams as `Win + 2` on the taskbar so you can flip to it from anywhere.

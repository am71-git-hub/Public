# Text Selection & Editing — Windows

These work in almost every Windows text box: browsers, web forms, Teams, Outlook, Word, Notepad, SDP.
Master this page and every app gets faster.

---

## Moving the cursor

| Keys | Moves to |
|---|---|
| `←` `→` | One character |
| `Ctrl + ←` / `Ctrl + →` | Start of previous / next word |
| `Home` / `End` | Start / end of line |
| `Ctrl + Home` / `Ctrl + End` | Start / end of document or box |
| `↑` `↓` | Line up / down |
| `Ctrl + ↑` / `Ctrl + ↓` | Previous / next paragraph (Word, many editors) |
| `Page Up` / `Page Down` | One screen up / down |

## Selecting — just add `Shift`

Any movement key + `Shift` selects instead of just moving.

| Keys | Selects |
|---|---|
| `Shift + ←/→` | One character |
| `Ctrl + Shift + ←` | Word **before** the cursor |
| `Ctrl + Shift + →` | Word **after** the cursor |
| `Shift + Home` | Back to start of line |
| `Shift + End` | Forward to end of line |
| `Shift + ↑/↓` | Up / down a line |
| `Ctrl + Shift + Home/End` | To start / end of document |
| `Ctrl + Shift + ↑/↓` | To start / end of paragraph (Word) |
| `Ctrl + A` | Everything |

**Whole line:** `Home` then `Shift + End`.
**Whole word you're inside:** `Ctrl + ←` then `Ctrl + Shift + →`.

## Mouse + keyboard selection

| Action | Selects |
|---|---|
| Double-click | Word |
| Triple-click | Line / paragraph (whole box in single-line inputs) |
| Double-click + drag | Word by word |
| Triple-click + drag | Paragraph by paragraph |
| Click, then `Shift + click` | Everything between the two points |
| `Ctrl + click` (Word) | Whole sentence |
| Click in left margin (Word) | Whole line; double-click margin = paragraph; triple = document |
| `Alt + drag` (Word) / `Shift + Alt + drag` (VS Code) | Rectangular **column** block |
| `Ctrl + drag-select` (Word, some editors) | Add a second, separate selection |

## Deleting

| Keys | Deletes |
|---|---|
| `Backspace` / `Delete` | Character before / after |
| `Ctrl + Backspace` | Word before |
| `Ctrl + Delete` | Word after |
| `Shift + Home`, `Delete` | Everything before the cursor on this line |
| `Shift + End`, `Delete` | Everything after the cursor on this line |

## Clipboard

| Keys | Action |
|---|---|
| `Ctrl + C` / `X` / `V` | Copy / cut / paste |
| `Ctrl + Shift + V` | Paste as plain text (browsers, Teams, Microsoft 365) |
| `Win + V` | Clipboard history (turn on the first time) |
| `Ctrl + Insert` / `Shift + Insert` | Old-school copy / paste (handy in some terminals and remote sessions) |

## Undo / redo / find

| Keys | Action |
|---|---|
| `Ctrl + Z` | Undo |
| `Ctrl + Y` (or `Ctrl + Shift + Z`) | Redo |
| `Ctrl + F` | Find |
| `F3` / `Shift + F3` | Next / previous match (many apps) |
| `Ctrl + H` | Find & replace (Word, Notepad, Excel, editors) |

## Formatting (where formatting exists)

| Keys | Action |
|---|---|
| `Ctrl + B` / `I` / `U` | Bold / italic / underline |
| `Ctrl + K` | Insert link |
| `Ctrl + Shift + 7` / `8` | Numbered / bulleted list (many web editors, Teams) |
| `Shift + F3` (Word) | Cycle UPPER / lower / Title case |
| `Ctrl + Space` (Word) | Clear character formatting |

## Context menu without the mouse

`Shift + F10` (or the **Menu** key next to right `Ctrl`) = right-click at the cursor.
Then use the arrow keys or the underlined letter.

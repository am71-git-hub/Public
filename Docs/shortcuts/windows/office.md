# Outlook, Excel & Word

Press **`Alt`** in any Office app to show **KeyTips** — letters over every ribbon button.
Keep pressing the letters to reach any command without the mouse (e.g. `Alt`, `H`, `B` → borders in Excel).

---

## Outlook (classic & new)

| Keys | Action |
|---|---|
| `Ctrl + 1` / `2` / `3` / `4` | Mail / Calendar / People / Tasks |
| `Ctrl + Shift + I` | Inbox |
| `Ctrl + N` | New item (in current view) |
| `Ctrl + Shift + M` | New email from anywhere |
| `Ctrl + R` | Reply |
| `Ctrl + Shift + R` | Reply all |
| `Ctrl + F` | **Forward** (not find!) |
| `Ctrl + E` or `F3` | Search |
| `Alt + S` or `Ctrl + Enter` | Send |
| `Ctrl + K` | Check / resolve names in To: |
| `Ctrl + Q` / `Ctrl + U` | Mark read / unread |
| `Ctrl + Shift + V` | Move to folder |
| `Insert` | Flag / unflag (classic) |
| `Delete` / `Ctrl + D` | Delete |
| `Ctrl + .` / `Ctrl + ,` | Next / previous message (in an open message) |
| `Ctrl + Shift + A` | New appointment |
| `↑` `↓` / `Enter` | Move through list / open message |

**Quick Steps** (classic Outlook, Home tab): one-click or `Ctrl + Shift + 1…9` actions like
"forward to SDP mailbox and move to Done". Set up the ones you do every day.

**Quick Parts / My Templates**: save standard replies and insert them in two keystrokes.

## Excel — data entry essentials

| Keys | Action |
|---|---|
| `Tab` / `Enter` | Confirm and move right / down |
| `Shift + Tab` / `Shift + Enter` | Confirm and move left / up |
| `F2` | Edit cell (cursor at end) |
| `Esc` | Cancel the edit |
| `Alt + Enter` | New line *inside* a cell |
| `Ctrl + Enter` | Put the same entry in **every selected cell** |
| `Ctrl + D` / `Ctrl + R` | Fill down / right from the cell above / left |
| `Ctrl + '` | Copy formula from cell above |
| `Ctrl + Shift + "` | Copy value from cell above |
| `Ctrl + ;` / `Ctrl + Shift + ;` | Today's date / current time |
| `Ctrl + E` | Flash Fill (Excel guesses the pattern — split names, etc.) |
| `Alt + ↓` | Pick from values already in the column / dropdown |
| `F4` | Repeat last action (or toggle `$` refs while editing a formula) |

### Moving & selecting

| Keys | Action |
|---|---|
| `Ctrl + arrow` | Jump to edge of data |
| `Ctrl + Shift + arrow` | Select to edge of data |
| `Ctrl + Home` / `Ctrl + End` | A1 / last used cell |
| `Shift + Space` / `Ctrl + Space` | Select row / column |
| `Ctrl + A` | Select current data region (again = whole sheet) |
| `Ctrl + PgUp` / `Ctrl + PgDn` | Previous / next sheet |
| `Ctrl + G` or `F5` | Go to a cell reference |

### Rows, tables, filters

| Keys | Action |
|---|---|
| `Ctrl + Shift + +` | Insert row/column/cells |
| `Ctrl + -` | Delete row/column/cells |
| `Ctrl + T` | Make a table |
| `Ctrl + Shift + L` | Filters on / off |
| `Alt + ↓` (on a header) | Open filter menu |
| `Ctrl + 1` | Format cells |
| `Alt + =` | AutoSum |
| `Ctrl + H` | Find & replace |

## Word — a few that pay off

| Keys | Action |
|---|---|
| `Ctrl + Shift + V` | Paste text only (current Microsoft 365) |
| `Ctrl + Shift + C` / `Ctrl + Shift + V` | Copy / paste formatting (older Word) |
| `Shift + F3` | Change case |
| `Ctrl + Space` | Clear character formatting |
| `Ctrl + Alt + 1/2/3` | Heading 1/2/3 |
| `Ctrl + Enter` | Page break |
| `F7` | Spell check |
| `F12` | Save As |
| `Ctrl + G` | Go to page |

## Start here

**[windows/help-desk-data-entry.md](windows/help-desk-data-entry.md)** — built for help desk / service desk work

## Printable versions

**[printable/](printable/)** ([open online](https://am71-git-hub.github.io/Public/Docs/shortcuts/printable/)) has a print-ready page for every sheet, made for a black & white laser printer
(Letter, landscape). Open `printable/index.html` in a browser, pick a sheet, and press `Ctrl + P`.
`help-desk-top-15.html` is a large-print copy of the 15 to learn first, for taping under the monitor;
`all.html` prints every sheet in one go. After editing a `.md` sheet, run `python3 printable/build.py` to regenerate.

## How to actually get good

1. **Learn 3–5 at a time.** More than that and none stick.
2. **Ban the mouse for one task.** e.g. "this week I don't click browser tabs."
3. **When you reach for the mouse, stop** and find the key. Slow today, fast forever.
4. **Combine moves.** `Ctrl + Shift + →` ×3 then `Ctrl + C` is one fluid motion once it's habit.
5. **Automate repeats.** Typed it three times? Make it a template, snippet, or site-search shortcut.

GNOME Desktop (Ubuntu default)

Linux · shortcuts

Super = the Windows key. Check or change everything in Settings → Keyboard → View and Customize Shortcuts. Other desktops (KDE, XFCE, Cinnamon) differ — but Alt+Tab, Super, and Ctrl+Alt+T are near-universal.

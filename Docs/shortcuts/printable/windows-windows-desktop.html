Windows Desktop — Windows 10 / 11

Windows · shortcuts

Window management, the Win key, dialog boxes, File Explorer, and Run commands a help desk tech should know.

Switching apps & windows

Alt+TabSwitch window (hold Alt, tap Tab to go further)
Alt+Shift+TabSwitch backwards
Ctrl+Alt+TabSticky switcher — stays open, pick with arrows + Enter
Win+TabTask View (all windows + virtual desktops)
Win+1…9Open / switch to pinned taskbar app #n (press again to cycle its windows)
Win+Shift+1…9Open a new window of app #n
Win+Alt+1…9Jump list (recent files) for app #n
Win+TCycle through taskbar icons (Enter to open)
Alt+EscCycle windows in the order they were opened

Arranging windows

Win+← / →Snap to left / right half
Win+↑Maximise (or snap to top half after a side snap)
Win+↓Restore / minimise
Win+ZSnap layouts menu (Windows 11)
Win+Shift+←/→Move window to the other monitor
Win+HomeMinimise everything except the active window
Win+DShow desktop (press again to restore)
Win+M / Win+Shift+MMinimise all / restore
Alt+SpaceWindow menu (then N minimise, X maximise, M move with arrows)
Alt+F4Close window (on the desktop: shut down dialog)

Virtual desktops

Win+Ctrl+DNew desktop
Win+Ctrl+←/→Switch desktop
Win+Ctrl+F4Close current desktop

Idea: desktop 1 = tickets & Teams, desktop 2 = admin tools / remote sessions.

The Win key

Win then typeSearch / launch anything (apps, settings, files)
Win+EFile Explorer
Win+RRun box
Win+ISettings
Win+XPower-user menu (Device Manager, Terminal, Disk Mgmt… — letters jump)
Win+LLock
Win+VClipboard history
Win+Shift+SSnip a region to clipboard
Win+PrtScnFull screenshot saved to Pictures\Screenshots
Win+.Emoji & symbols panel
Win+HVoice typing
Win+AQuick settings (Wi-Fi, volume…)
Win+NNotifications / calendar
Win+Ctrl+EnterNarrator on/off (know this in case a user turns it on by accident)
Win++ / Win+EscMagnifier on / off (same)
Win+Ctrl+Shift+BRestart the graphics driver (black/frozen screen fix)
Ctrl+Shift+EscTask Manager directly
Ctrl+Alt+DelSecurity screen (lock, switch user, Task Manager)

Dialog boxes & forms (old-style Windows apps)

Tab / Shift+TabNext / previous control
EnterDefault button (usually OK)
EscCancel
SpacePress focused button / toggle checkbox
Alt+underlined letterJump to that control (press Alt to reveal underlines)
Arrow keysMove within a radio group or list
Alt+↓ or F4Open a dropdown
Type lettersJump to matching item in a list
Ctrl+Tab / Ctrl+Shift+TabNext / previous tab in a tabbed dialog

File Explorer

Alt+D or Ctrl+LAddress bar (type a path like \\server\share or %appdata%)
Alt+↑Up one folder
Alt+← / →Back / forward
Ctrl+E or Ctrl+FSearch box
F2Rename
Ctrl+Shift+NNew folder
Alt+EnterProperties
Ctrl+Shift+C (Win 11)Copy the file's full path
Shift+right-clickExtended menu incl. "Copy as path" (Win 10)
Ctrl+mouse wheelChange icon size / view
Shift+DeleteDelete permanently (no Recycle Bin)

Run box commands (Win+R) — help desk favourites

cmd / powershellCommand prompt / PowerShell (Ctrl+Shift+Enter = run as admin)
controlControl Panel
appwiz.cplPrograms and Features (uninstall)
ncpa.cplNetwork adapters
devmgmt.mscDevice Manager
services.mscServices
eventvwrEvent Viewer
compmgmt.mscComputer Management
diskmgmt.mscDisk Management
lusrmgr.mscLocal users & groups
printmanagement.mscPrint Management (Pro/Enterprise)
dsa.mscActive Directory Users & Computers (if RSAT installed)
mstscRemote Desktop
msinfo32System info (model, serial-ish, RAM, BIOS)
winverWindows version / build
taskmgrTask Manager
%temp%Temp folder
\\computername\c$Admin share on a remote PC (with rights)

Most of these also work typed straight into the Start menu after pressing Win.

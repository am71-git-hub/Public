Microsoft Teams (new Teams, Windows desktop app)

Windows · shortcuts

Ctrl+. shows the official list inside Teams — Microsoft changes these, so trust that over any sheet. In the browser version, some keys differ (e.g. Ctrl+Alt+E for search) because the browser owns them.

Getting around

Ctrl+.Show keyboard shortcuts
Ctrl+ESearch box (type a person's name to jump to their chat)
Ctrl+NNew chat
Ctrl+1, 2, 3…Apps in the left bar, in order (Activity, Chat, Teams, Calendar…)
Ctrl+FSearch inside the current chat / channel
F6 / Ctrl+F6Move focus between regions (left bar, list, conversation, compose)
↑ ↓Move through chat list or messages once focused
Ctrl+,Settings
EscBack out of whatever you're in

Writing messages

EnterSend
Shift+EnterNew line (don't send)
Ctrl+Shift+XExpand compose box — then Enter = new line, Ctrl+Enter = send
Ctrl+B / I / UBold / italic / underline
Ctrl+Shift+VPaste as plain text
@ + name, then Tab/EnterMention someone
Type ```Start a code block — great for pasting error messages and logs
Type ` around textInline code (e.g. a hostname)
↑ (in empty compose box)Edit your last message (in many versions)

Habits that save time

  • Pin your team lead and the main help-desk channel (… → Pin) so they're always at the top.
  • Use Saved messages (bookmark a message) for instructions you'll need again.
  • Win+Shift+S then Ctrl+V in a chat = instant screenshot to a colleague.
  • Set Teams as Win+2 on the taskbar so you can flip to it from anywhere.

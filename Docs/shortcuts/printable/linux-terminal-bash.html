Terminal & Bash — Linux

Linux · shortcuts

Line editing in bash comes from readline, so these also work in python, psql, mysql, gdb, and most other interactive prompts. They're the terminal equivalent of Ctrl+←, Shift+End etc. on Windows.

For multiplexing and editing, see the existing docs: tmux and vim.

Moving on the command line

Ctrl+A / Ctrl+EStart / end of line
Alt+B / Alt+FBack / forward one word
Ctrl+← / Ctrl+→Back / forward one word (most terminals)
Ctrl+B / Ctrl+FBack / forward one character
Ctrl+XXToggle between start of line and current position

Deleting & the kill ring (readline's clipboard)

Ctrl+WCut the word before the cursor
Alt+DCut the word after the cursor
Alt+BackspaceCut word before (stops at / and . — nicer for paths)
Ctrl+UCut from cursor to start of line
Ctrl+KCut from cursor to end of line
Ctrl+YPaste (yank) the last cut
Alt+YAfter Ctrl+Y: cycle through older cuts
Ctrl+DDelete character under cursor (on empty line: exit shell)
Ctrl+_ or Ctrl+X Ctrl+UUndo

Trick: typed a long command but need to run something else first? Ctrl+U (cut it), run the other command, then Ctrl+Y to get it back.

Editing tricks

Alt+TSwap the last two words
Ctrl+TSwap the last two characters
Alt+U / Alt+L / Alt+CUPPERCASE / lowercase / Capitalise word
Ctrl+X Ctrl+EOpen the current command in $EDITOR (vim) — for long one-liners
Alt+.Insert the last argument of the previous command (repeat for older ones)
Alt+#Comment out the line and save it in history (run it later)
Tab / Tab TabComplete / show all completions

History

↑ / ↓Previous / next command
Ctrl+RSearch history backwards — keep pressing to go further
Ctrl+SSearch forwards (needs stty -ixon in ~/.bashrc)
Ctrl+GCancel the search
Enter / →Run the match / take it for editing
!!Previous command (sudo !! = "that, but as root")
!$Last argument of previous command
!*All arguments of previous command
!sshRe-run the last command starting with ssh
^old^newRe-run previous command, replacing old with new
history | grep fooFind old commands

Add to ~/.bashrc for better history:

HISTSIZE=100000
HISTFILESIZE=200000
HISTCONTROL=ignoreboth:erasedups
shopt -s histappend
# Up/Down search history by what you've already typed:
bind '"\e[A": history-search-backward'
bind '"\e[B": history-search-forward'

Process control

Ctrl+CInterrupt (stop) the running program
Ctrl+ZSuspend it — then bg (background) or fg (bring back)
Ctrl+DEnd of input / log out
Ctrl+LClear screen (keeps current line)
Ctrl+S / Ctrl+QFreeze / unfreeze output (if the terminal "hangs", try Ctrl+Q)
jobsList suspended/background jobs

Pagers (less, man) — same keys as vim

Space / bPage down / up
j / kLine down / up
g / GTop / bottom
/word / ?wordSearch forward / back; n / N next / previous
F (in less)Follow the file like tail -f; Ctrl+C to stop
qQuit

Directory hopping

cd -Back to previous directory
cdHome
pushd dir / popdStack of directories
Ctrl+R then cd Find that long cd you did yesterday

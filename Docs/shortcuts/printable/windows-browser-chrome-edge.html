Browser — Chrome & Edge (Windows)

Windows · shortcuts

Most of your apps (SDP and friends) live in a browser, so this is where keyboard skill pays off most. Almost all of these are identical in Chrome, Edge and Firefox, and on Linux.

Tabs

Ctrl+TNew tab
Ctrl+WClose tab
Ctrl+Shift+TReopen last closed tab (repeat to go further back)
Ctrl+Tab / Ctrl+Shift+TabNext / previous tab
Ctrl+PgDn / Ctrl+PgUpNext / previous tab (alternative)
Ctrl+1…8Jump to tab 1–8
Ctrl+9Jump to last tab
Ctrl+Shift+ASearch open tabs (Chrome)
Ctrl+NNew window
Ctrl+Shift+NIncognito / InPrivate window (test logins without your cookies)
Right-click tab → PinKeep SDP/Teams web pinned at the left; Ctrl+1 always gets it

Links

Ctrl+click / middle-clickOpen in background tab
Ctrl+Shift+clickOpen in new tab and switch to it
Shift+clickOpen in new window
Tab / Shift+TabMove focus link to link; Enter opens it

Navigation

Alt+← / Alt+→Back / forward
F5 or Ctrl+RReload
Ctrl+F5 or Ctrl+Shift+RHard reload (bypass cache — fixes "it looks broken")
EscStop loading
Space / Shift+SpacePage down / up
Home / EndTop / bottom of page
F11Full screen
Ctrl++ / Ctrl+- / Ctrl+0Zoom in / out / reset

Address bar

Ctrl+L, Alt+D or F6Focus address bar (and select the URL — Ctrl+C copies it)
Ctrl+K or Ctrl+ESearch with default engine
Alt+EnterOpen what you typed in a new tab
Ctrl+EnterAdd www. and .com
Shift+Delete on a suggestionRemove that autocomplete suggestion
keyword + SpaceUse a site search shortcut (see below)

Site search shortcuts — the biggest time saver

Settings → Search engine → Site search → Add. Put %s where the search term or ID goes.

ShortcutExample URLUse
sdpyour SDP ticket URL with the number replaced by %ssdp 48211 → opens the ticket
kbyour KB search URL with %skb vpn
adyour user-lookup page with %sad jsmith

Find & select on the page

Ctrl+FFind
Enter / Shift+EnterNext / previous match (while find bar is open)
Ctrl+G / Ctrl+Shift+GNext / previous match
EscClose find — the match stays selected, so Ctrl+C copies it
F7Caret browsing: select page text with Shift+arrows like a document

Forms (web apps like SDP)

Tab / Shift+TabNext / previous field
SpaceToggle checkbox / press button
↑ ↓Change radio button
Alt+↓Open a standard dropdown
Type lettersJump/filter in a dropdown
EnterSubmit (careful — in many forms Enter in a one-line field submits)
↓ in a fieldShow autofill suggestions; Shift+Delete removes one

Useful for troubleshooting users' browsers

Ctrl+Shift+DeleteClear browsing data (cache/cookies — the classic fix)
Ctrl+HHistory
Ctrl+JDownloads
Ctrl+DBookmark page
Ctrl+Shift+BShow / hide bookmarks bar
Ctrl+Shift+OBookmark manager
Ctrl+PPrint / save as PDF
F12 or Ctrl+Shift+IDeveloper tools (console errors)
Shift+EscBrowser's own task manager (which tab is eating memory)
chrome://settings / edge://settingsSettings pages — type straight in the address bar

Bookmark-bar trick: rename bookmarks to just an icon (blank name) to fit dozens on the bar, or put them in folders and use Ctrl+L, type part of the name, and pick from suggestions.

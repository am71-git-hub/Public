Text Selection & Editing — Windows

Windows · shortcuts

These work in almost every Windows text box: browsers, web forms, Teams, Outlook, Word, Notepad, SDP. Master this page and every app gets faster.

Moving the cursor

← →One character
Ctrl+← / Ctrl+→Start of previous / next word
Home / EndStart / end of line
Ctrl+Home / Ctrl+EndStart / end of document or box
↑ ↓Line up / down
Ctrl+↑ / Ctrl+↓Previous / next paragraph (Word, many editors)
Page Up / Page DownOne screen up / down

Selecting — just add Shift

Any movement key + Shift selects instead of just moving.

Shift+←/→One character
Ctrl+Shift+←Word before the cursor
Ctrl+Shift+→Word after the cursor
Shift+HomeBack to start of line
Shift+EndForward to end of line
Shift+↑/↓Up / down a line
Ctrl+Shift+Home/EndTo start / end of document
Ctrl+Shift+↑/↓To start / end of paragraph (Word)
Ctrl+AEverything

Whole line: Home then Shift+End. Whole word you're inside: Ctrl+← then Ctrl+Shift+→.

Mouse + keyboard selection

Double-clickWord
Triple-clickLine / paragraph (whole box in single-line inputs)
Double-click + dragWord by word
Triple-click + dragParagraph by paragraph
Click, then Shift+clickEverything between the two points
Ctrl+click (Word)Whole sentence
Click in left margin (Word)Whole line; double-click margin = paragraph; triple = document
Alt+drag (Word) / Shift+Alt+drag (VS Code)Rectangular column block
Ctrl+drag-select (Word, some editors)Add a second, separate selection

Deleting

Backspace / DeleteCharacter before / after
Ctrl+BackspaceWord before
Ctrl+DeleteWord after
Shift+Home, DeleteEverything before the cursor on this line
Shift+End, DeleteEverything after the cursor on this line

Clipboard

Ctrl+C / X / VCopy / cut / paste
Ctrl+Shift+VPaste as plain text (browsers, Teams, Microsoft 365)
Win+VClipboard history (turn on the first time)
Ctrl+Insert / Shift+InsertOld-school copy / paste (handy in some terminals and remote sessions)

Undo / redo / find

Ctrl+ZUndo
Ctrl+Y (or Ctrl+Shift+Z)Redo
Ctrl+FFind
F3 / Shift+F3Next / previous match (many apps)
Ctrl+HFind & replace (Word, Notepad, Excel, editors)

Formatting (where formatting exists)

Ctrl+B / I / UBold / italic / underline
Ctrl+KInsert link
Ctrl+Shift+7 / 8Numbered / bulleted list (many web editors, Teams)
Shift+F3 (Word)Cycle UPPER / lower / Title case
Ctrl+Space (Word)Clear character formatting

Context menu without the mouse

Shift+F10 (or the Menu key next to right Ctrl) = right-click at the cursor. Then use the arrow keys or the underlined letter.

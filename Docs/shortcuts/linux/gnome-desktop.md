# GNOME Desktop (Ubuntu default)

`Super` = the Windows key. Check or change everything in **Settings → Keyboard → View and Customize Shortcuts**.
Other desktops (KDE, XFCE, Cinnamon) differ — but `Alt + Tab`, `Super`, and `Ctrl + Alt + T` are near-universal.

---

## Launching & switching

| Keys | Action |
|---|---|
| `Super` | Activities overview — start typing to launch anything |
| `Super + A` | App grid |
| `Ctrl + Alt + T` | Terminal (Ubuntu) |
| `Super + 1…9` | Open / switch to dock app #n |
| `Super + Shift + 1…9` | New window of dock app #n (Ubuntu dock) |
| `Alt + Tab` / `Alt + Shift + Tab` | Switch applications |
| `` Alt + ` `` | Switch windows **of the same app** |
| `Super + Tab` | Switch applications (same as Alt+Tab) |
| `Alt + F2` | Run a command |
| `Alt + F4` | Close window |
| `Super + L` | Lock screen |

## Windows

| Keys | Action |
|---|---|
| `Super + ←` / `→` | Snap left / right half |
| `Super + ↑` / `↓` | Maximise / restore |
| `Super + H` | Hide (minimise) |
| `Super + Shift + ←/→` | Move window to other monitor |
| `Super + D` | Show desktop (Ubuntu) |
| `Alt + F7` / `Alt + F8` | Move / resize with keyboard |
| `Alt + Space` | Window menu |
| `Super + drag` | Move a window from anywhere inside it |

## Workspaces

| Keys | Action |
|---|---|
| `Super + PgUp` / `PgDn` | Previous / next workspace |
| `Ctrl + Alt + ←/→` | Previous / next workspace (common default) |
| `Super + Shift + PgUp/PgDn` | Move window to previous / next workspace |
| `Super + Home` / `End` | First / last workspace |

## Screenshots & misc

| Keys | Action |
|---|---|
| `Print` | Screenshot tool (region / window / screen; saves + copies) |
| `Shift + Print` | Full-screen screenshot |
| `Alt + Print` | Window screenshot |
| `Ctrl + Alt + Shift + R` | Screen recording toggle |
| `Super + V` | Notification list / calendar |
| `Super + .` or `Ctrl + .` | Emoji picker (GTK text fields) |
| `Ctrl + Shift + U`, hex, `Space` | Type any Unicode character |
| `Alt + F2`, `r`, `Enter` | Restart GNOME Shell (X11 only) |

## Files (Nautilus)

| Keys | Action |
|---|---|
| `Ctrl + L` | Type a path |
| `Alt + ↑` / `Backspace`* | Parent folder |
| `Alt + ←` / `→` | Back / forward |
| `Ctrl + H` | Show / hide hidden files |
| `F2` | Rename |
| `Ctrl + Shift + N` | New folder |
| `Ctrl + 1` / `Ctrl + 2` | List / grid view |
| Just type | Search in current folder |

## Make your own

Settings → Keyboard → Custom Shortcuts → **+**. Examples:

| Shortcut | Command |
|---|---|
| `Super + Return` | `alacritty` |
| `Super + Shift + R` | `alacritty -e ssh -t myserver tmux new -A -s main` |
| `Super + B` | `firefox` |

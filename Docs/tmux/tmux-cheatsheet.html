tmux cheatsheet

Every key below is pressed after the prefix Ctrl+b — except shell lines and command-prompt lines.

Sessions from the shell

tmux new -s worknew named session
tmux lslist sessions
tmux attach -t workattach to session
tmux new -As workattach, or create if missing
tmux kill-session -t workkill a session
tmux kill-serverkill everything

Sessions inside tmux

ddetach (session keeps running)
$rename session
spick session from a list
( / )previous / next session

Windows tabs

cnew window
,rename window
n / pnext / previous window
0…9jump to window by number
llast-used window
wpick window from a list
ffind window by name
.move window to new index
&kill window (confirms)

Panes splits

%split left | right
"split top / bottom
←↑↓→move to pane in that direction
ocycle through panes
;last-used pane
qshow pane numbers (press one to jump)
zzoom pane full-screen (toggle)
!break pane out into its own window
{ / }swap pane with previous / next
xkill pane (confirms)

Resize & layouts

Ctrl+←↑↓→resize pane by 1 (hold prefix, repeat)
Alt+←↑↓→resize pane by 5
Spacecycle preset layouts
Alt+1…5even-horizontal … tiled layout

Misc

:command prompt

Command prompt after :

setw synchronize-panestype into all panes at once (toggle)
swap-window -t 0move current window to slot 0

source ~/.tmux.confreload config

~/.tmux.conf quick-start

# friendlier prefix: Ctrl-a
unbind C-b
set -g prefix C-a
bind C-a send-prefix

set -g mouse on
setw -g mode-keys vi
set -g base-index 1          # windows at 1
setw -g pane-base-index 1
set -g history-limit 50000
set -g escape-time 0

# prefix r = reload config
bind r source-file ~/.tmux.conf \; \
  display "config reloaded"

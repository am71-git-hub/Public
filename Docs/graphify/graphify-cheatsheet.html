graphify cheatsheet

/graphify lines run inside your AI assistant (Claude Code) · $ lines run in the shell. Output lands in graphify-out/.

Install once

uv tool install graphifyyinstall CLI (note: double-y pkg)
graphify installregister /graphify skill (Claude Code)
graphify install --projectskill into this repo only
uv tool upgrade graphifyyupdate, then re-run install
graphify uninstallremove everywhere (--purge: + output)

Build a graph

graphify .map the whole project
graphify . --updatere-extract changed files only
graphify . --mode deepricher relationship extraction
graphify . --no-vizskip HTML (huge repos)
graphify . --cluster-onlyrecluster, no re-extract
graphify . --wikimarkdown wiki from the graph
graphify . --obsidianObsidian vault

Output graphify-out/

graph.htmlinteractive map — click, filter, search
GRAPH_REPORT.mdgod nodes, surprises, questions
graph.jsonfull graph — what query reads

Add content

graphify add <arxiv-url>pull a paper into the graph
graphify add <youtube-url>transcribe a video in ([video])

Ask the graph the payoff

graphify query "…?"answer from the graph, not grep
graphify path "A" "B"shortest path between two nodes
graphify explain "Node"everything about one thing
… --dfs --budget 1500deeper walk, bigger answer
graphify query \
  "what connects auth to the db?"

Keep it fresh

graphify hook installrebuild on every commit (free, AST)
graphify hook statuscheck hooks
graphify . --watchlive sync as files change
graphify claude installmake Claude graph-first (per repo)

Headless / CI no IDE

graphify extract .code-only: local, offline, no key
… --backend claude-clidocs via your Claude subscription
… --backend ollamafully local LLM
… --backend geminior: claude, openai, bedrock, azure…

Survival kit

command not found→ uv tool update-shell, new terminal
uvx graphify fails→ uvx --from graphifyy graphify
docs nodes empty→ needs LLM: skill or backend key
graph shrank→ graphify extract . --force

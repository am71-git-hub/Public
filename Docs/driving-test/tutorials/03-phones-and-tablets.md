# 3 · Phones and tablets

[← Back to the G1 study kit](../README.md)

The app is built for touch screens and works on older tablets too.

**Easiest:** open **https://am71-git-hub.github.io/Public/Docs/driving-test/site/** in your phone's browser, then
[add a home-screen icon](#add-a-home-screen-icon). Done.

Want to run your own copy instead? There are three ways.

| Way | Android | iPhone / iPad | Needs |
|---|---|---|---|
| **A. Open from a computer on your Wi-Fi** | ✅ | ✅ | A computer running a tiny web server ([tutorial 4](04-share-on-your-wifi.md)) |
| **B. Open the file directly** | ✅ usually | ❌ | Just the file |
| **C. Put it on free web hosting** | ✅ | ✅ | A free GitHub account |

---

## A. Open it from a computer on your Wi-Fi (best for most homes)

1. On a computer, follow [Share it on your Wi-Fi](04-share-on-your-wifi.md). You end up with an address like
   `http://192.168.1.50:8095`.
2. On the phone or tablet (on the **same Wi-Fi**), type that address into Chrome or Safari.
3. Add a home-screen icon (below).

Each device keeps its **own** progress.

## B. Open the file directly (Android)

1. On the phone, open [`site/index.html`](../site/index.html) on GitHub in Chrome and tap **Download raw file**
   (on the mobile site you may need to tap **⋮** or switch to **Desktop site** to see it).
2. Open **Files** / **Downloads** and tap the file. Choose **Chrome** if asked.

If it shows plain text or a blank page, your file app opened it in a basic viewer.
Use way A or C instead.

**iPhone and iPad can't run the app from a downloaded file**: the Files app shows HTML without running
its code. Use way A or C.

## C. Put it on free web hosting (works anywhere, any device)

GitHub Pages hosts static pages for free. You get a normal web address you can open on any device, anywhere.

1. Sign in to GitHub and **Fork** this repository (button at the top right). You now have your own copy.
2. In your fork: **Settings** → **Pages**.
3. Under **Build and deployment**: Source **Deploy from a branch**, Branch **main**, folder **/ (root)** → **Save**.
4. Wait a minute or two. Your app is at:

   ```
   https://<your-github-name>.github.io/<repository-name>/Docs/driving-test/site/
   ```

   and the no-save version at `…/driving-test/site/g1-practice-no-save.html`.

Your progress still stays on each device. GitHub only serves the page; it never sees your answers.

## Add a home-screen icon

Once the app is open from a web address (way A or C):

| Device | Steps |
|---|---|
| **Android (Chrome)** | **⋮** menu → **Add to Home screen** → **Add** |
| **iPhone / iPad (Safari)** | **Share** button (square with arrow) → **Add to Home Screen** → **Add** |
| **Samsung Internet** | **☰** menu → **Add page to** → **Home screen** |

The icon opens the app in one tap, like any other app.

## Tips for small screens

- **A− / A+** in **⚙️ Text size and read aloud** changes the text size.
- Turn on **Read every question aloud automatically** to practise hands-free.
- Rotate a tablet sideways for bigger sign pictures.

# 1 · Open the file

[← Back to the G1 study kit](../README.md)

The whole practice app is **one HTML file**: [`site/index.html`](../site/index.html). Everything it needs
(questions, pictures, styles, code) is packed inside. You don't install anything and you don't need internet
after you've downloaded it.

---

## Step 1: Download it

**Just the app (about 1.5 MB):**

1. Open [`driving-test/site/index.html`](../site/index.html) on GitHub.
2. Click **Download raw file** (the ⬇ download icon at the top right of the file view).
3. Your browser saves it, usually to your **Downloads** folder, as `index.html`.

   Tip: rename it to something you'll recognise, like `G1-practice.html`.

**Everything (app + study guides + question pages):**

1. Go to the repository's main page on GitHub.
2. Click the green **Code** button → **Download ZIP**.
3. Unzip it. The app is at `driving-test/site/index.html`.

**With git** (if you have it):

```bash
git clone <this repository's URL>
```

## Step 2: Open it

| Computer | How |
|---|---|
| **Windows** | Double-click the file. If it opens in Notepad instead: right-click → **Open with** → **Microsoft Edge** or **Google Chrome**. |
| **Mac** | Double-click. It opens in Safari. To use Chrome: right-click → **Open With** → **Google Chrome**. |
| **Linux** | Double-click in your file manager, or run `xdg-open G1-practice.html`. |
| **Chromebook** | Open the **Files** app → **Downloads** → click the file. |

You should see **G1 Practice** with a 🚸 Signs card and a 📘 Rules card. Pick one and start.

## Step 3: Keep it in one place

Your progress is saved **by your browser**, tied to that file on that computer.

- Opening the file in a **different browser** starts with fresh progress.
- **Moving or renaming** the file can also start fresh progress in some browsers.
- So pick a home for it (Documents, Desktop) and leave it there.

Want a shortcut? Drag the file onto your desktop or taskbar, or bookmark the page once it's open
(`Ctrl + D` / `Cmd + D`).

## Which browser?

Any modern browser works: **Chrome, Edge, Firefox, Safari**, including older tablets.
For **read aloud**, Chrome, Edge and Safari have the best built-in voices.

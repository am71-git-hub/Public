cat cheatsheet

Reads files (or stdin) in order, writes to stdout. The shell's > >> | do the rest.

View

cat fileprint a file
cat f1 f2print files back to back
cat *.logall matches, alphabetical order
cat -n filenumber every line
cat -b filenumber non-blank lines only
cat -s filesqueeze repeated blank lines
less filelong file? use the pager instead

Create & append

cat > ftype a new file (end: Ctrl+d)
cat >> fappend typed lines to f
cat a b > cmerge a+b into c (c overwritten)
cat a >> bglue a onto the end of b

Heredoc quick-start

cat > conf.toml << 'EOF'
[settings]
color = "blue"
EOF
# 'EOF' quoted → $vars stay literal
# unquoted EOF → $vars expand
# <<- strips leading tabs

Stdin & "-"

catecho stdin until Ctrl+d
cat -"-" means stdin explicitly
cat hdr - ftrstdin between two files
cat -- -filefile whose name starts with "-"

See invisibles whitespace bugs

cat -A fshow all: tabs, line ends, ctrl chars
cat -E f$ at each line end (trailing spaces!)
cat -T ftabs shown as ^I
cat -v fcontrol chars as ^X, safe-ish view
# what -A output means
^I      a real TAB   (Makefiles need these)
text $  line end     (space before $ = trailing)
^M$     CRLF         (Windows file → dos2unix)

Pipelines

cat *.csv | sortmerge many files into one stream
dmesg | cat -nnumber any command's output
grep pat filenot cat file | grep — grep opens files
wc -l < filenot cat file | wc — redirect instead

System files /proc /sys

cat /etc/os-releasewhat distro is this
cat /proc/cpuinfoCPU details
cat /proc/meminfomemory details
cat /sys/class/power_supply/BAT0/capacitybattery %

The cat family

tac flast line first (cat reversed)
nl ffancier line numbering
zcat f.gzcat a gzip file in place
head f / tail ffirst / last 10 lines
tail -f logfollow a growing file
cmd | tee fwatch output AND save it
bat fcat + colors + paging (extra install)

Traps

cat a b > a✗ destroys a — shell truncates it first
sudo cat f > /root/x✗ redirect isn't sudo — use | sudo tee
cat binary✗ may scramble terminal — xxd | less
resetfixes a scrambled terminal (type blind)

Recipes

# merge CSVs, one header
head -1 a.csv > out.csv
tail -n +2 -q *.csv >> out.csv

# search rotated logs in place
zcat syslog.*.gz | grep -i error

# file → variable (no cat needed)
data=$(< file)

# write file as root
cat f | sudo tee /etc/x >/dev/null

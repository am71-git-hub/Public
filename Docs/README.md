# Docs

Guides, cheat sheets and study tools. Each folder stands on its own: open its README to start.

| Folder | What's in it |
|---|---|
| [driving-test](driving-test/) | **Ontario G1 written test study kit**: a one-file practice app (600+ questions, mock test, flashcards, read aloud), study guides, and tutorials for running it anywhere |
| [shortcuts](shortcuts/) | **Keyboard shortcut cheat sheets** for Windows (help desk / data entry, browser, Teams, Office) and Linux (bash, clipboard, GNOME), with printable black & white versions |
| [tmux](tmux/) | **tmux tutorial** and key reference, plus a Claude Code status indicator for the tmux tab bar |
| [nethack](nethack/) | **NetHack tutorials**: beginner guide, quick reference, crib sheet, full tutorial, the Guidebook, and ready-made configs |
| [docs-vim](docs-vim/) | **Vim tutorial**: modes, motions, a cheat sheet and a learning path |
| [cat](cat/) | **`cat` beginner tutorial** and full reference, with an HTML cheat sheet |
| [graphify](graphify/) | **Graphify tutorial**: turn a codebase or docs folder into a queryable knowledge graph for AI coding assistants |
| [claude-code-docs](claude-code-docs/) | **Claude Code** reference: commands, settings, permissions, hooks, MCP |
| [term-emulators](term-emulators/) | **Terminal emulators and graphics**: what's possible over SSH (text, Sixel, Kitty protocol) |
| [weather-docs](weather-docs/) | **Environment Canada weather API** reference: every platform, endpoint and field, with working examples |

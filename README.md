# Public docs

Free guides, cheat sheets, study tools and small projects. Guides live in [`Docs/`](Docs/); each folder stands on its own, so open its README to start.

**Live links:** [G1 practice app](https://am71-git-hub.github.io/Public/Docs/driving-test/site/) · [printable shortcut sheets](https://am71-git-hub.github.io/Public/Docs/shortcuts/printable/) · [browse as a website](https://am71-git-hub.github.io/Public/)

### Docs

| Folder | What's in it |
|---|---|
| [driving-test](Docs/driving-test/) | **Ontario G1 written test study kit**: a one-file practice app (600+ questions, mock test, flashcards, read aloud), study guides, and tutorials for running it anywhere |
| [shortcuts](Docs/shortcuts/) | **Keyboard shortcut cheat sheets** for Windows (help desk / data entry, browser, Teams, Office) and Linux (bash, clipboard, GNOME), with printable black & white versions |
| [tmux](Docs/tmux/) | **tmux tutorial** and key reference, plus a Claude Code status indicator for the tmux tab bar |
| [nethack](Docs/nethack/) | **NetHack tutorials**: beginner guide, quick reference, crib sheet, full tutorial, the Guidebook, and ready-made configs |
| [docs-vim](Docs/docs-vim/) | **Vim tutorial**: modes, motions, a cheat sheet and a learning path |
| [cat](Docs/cat/) | **`cat` beginner tutorial** and full reference, with an HTML cheat sheet |
| [graphify](Docs/graphify/) | **Graphify tutorial**: turn a codebase or docs folder into a queryable knowledge graph for AI coding assistants |
| [claude-code-docs](Docs/claude-code-docs/) | **Claude Code** reference: commands, settings, permissions, hooks, MCP |
| [term-emulators](Docs/term-emulators/) | **Terminal emulators and graphics**: what's possible over SSH (text, Sixel, Kitty protocol) |
| [weather-docs](Docs/weather-docs/) | **Environment Canada weather API** reference: every platform, endpoint and field, with working examples |

## Projects
